# Совместимость оборудования для игр в Linux

## Минимальные системные требования

- **Прошивка**: UEFI (загрузка CSM/Legacy [**НЕ ПОДДЕРЖИВАЕТСЯ**](../General/FAQ.md#does-bazzite-support-csmlegacy-boot))
- **Процессор (CPU)** : четырехъядерный процессор с частотой 2 ГГц или лучше
  - **Архитектура**: x86-64
- **Системная память (RAM)**: 8 ГБ
- **Графика**: видеокарта с поддержкой Vulkan 1.3 или новее
- **Хранилище**: 50 ГБ свободного места на внутреннем **твердотельном накопителе (SSD)**
  - **Рекомендуемое хранилище**: 120 ГБ свободного места на внутреннем **твердотельном накопителе (SSD)**
  - Существующие диски **должны** использовать **GPT**. Попытка установить Bazzite на диск с разметкой MBR (Master Boot Record) завершится ошибкой.
    - Microsoft предоставляет [инструмент для преобразования существующих установок Windows в GPT](https://learn.microsoft.com/en-us/windows/deployment/mbr-to-gpt).
    !!! warning "Перед любыми операциями с диском обязательно создайте резервную копию всех важных личных файлов!"
  - **Внешнее хранилище и дополнительные диски**: все диски должны быть отформатированы в **BTRFS (твердотельные накопители [SSD])** или **Ext4 (жесткие диски [HDD])**. _Создайте резервную копию файлов и переформатируйте диски после установки._
  > Подробнее см. [здесь](#unsupported-filesystems-for-secondary-drives).
- **Сеть**: стабильное подключение к интернету без ограничений по трафику (_не требуется для установки_)

!!! note

    Некоторые периферийные устройства **не** совместимы с Linux, а значит и с Bazzite, в зависимости от производителя. Для **Wi-Fi-адаптеров** доступен [список **известных совместимых** USB Wi-Fi-адаптеров](https://github.com/morrownr/USB-WiFi/blob/main/home/USB_WiFi_Adapters_that_are_supported_with_Linux_in-kernel_drivers.md).

>[**Hardware for Linux**](https://linux-hardware.org/?view=computers) хорошо показывает, насколько хорошо OEM-оборудование поддерживается на Linux-десктопе.

### Требования Steam Gaming Mode

!!! note

    Эти требования относятся только к [образам Bazzite-Deck](/Handheld_and_HTPC_edition/Steam_Gaming_Mode.md), которые поставляются со всеми ISO Bazzite для портативных устройств, и похожи на требования [SteamOS](https://store.steampowered.com/steamos/)

- Современный GPU AMD
  - Серия RX 4xx и новее
    - Встроенные GPU 600M/700M тоже поддерживаются
- GPU Intel Arc поддерживаются с **небольшими оговорками** по сравнению с оборудованием AMD
- GPU NVIDIA поддерживается с [**существенными оговорками**](/Handheld_and_HTPC_edition/quirks/#nvidia-gpu-exclusive-issues-with-steam-gaming-mode) по сравнению с оборудованием AMD. К сожалению, это вне контроля сопровождающих Bazzite.
- Требуется учетная запись [**Steam**](https://store.steampowered.com/)
  - Если у вас еще нет учетной записи, ее можно создать после установки

## GPU с поддержкой Vulkan

!!! attention

    Игры в Linux сильно зависят от совместимого оборудования с поддержкой [Vulkan](/General/terms/#software).

### Просмотр версии Vulkan для вашего GPU

Если вы используете устройство со старым или слабым GPU, который поддерживает **Vulkan 1.1 или 1.2**, но не **Vulkan 1.3 или новее**, используйте Proton-CachyOS с DXVK-Sarek, как описано ниже. Чтобы проверить, какую версию Vulkan использует ваш GPU, введите в **терминале**:

```bash
vulkaninfo | grep 'Instance Version'
```

![Vulkan Command](https://github.com/user-attachments/assets/ccca14ca-3001-4aa6-bf47-e0dcbdb73936)

- Если вывод меньше `1.3` в `Vulkan Instance Version:` или команда вообще не работает, вы столкнетесь с проблемами, включая неиграбельные игры и более низкую производительность.

- Очень старым устройствам может понадобиться трансляция OpenGL, которая работает медленнее, вызывает графические проблемы и так далее.

> Попробуйте [**DXVK-Sarek**](https://github.com/pythonlover02/DXVK-Sarek), если у вас оборудование, которое поддерживает только Vulkan 1.1/1.2. Он официально поддерживается в [Proton-CachyOS](https://github.com/CachyOS/proton-cachyos) и включается через [переменную окружения](/Gaming/launch-options-env-variables) `PROTON_DXVK_SAREK=1`. Однако не используйте этот параметр с играми, где есть античит, или с многопользовательскими играми.

!!! info "Вы можете установить [Proton-CachyOS](https://github.com/CachyOS/proton-cachyos) через ProtonPlus или ProtonUp-Qt."

### GPU без поддержки Vulkan

Если ваш GPU совсем не поддерживает Vulkan, нужно использовать этот **параметр запуска для всех игр, работающих через Proton**:

```bash
PROTON_USE_WINED3D=1 %command%
```

Вместо Vulkan будет использоваться трансляция OpenGL.

## Файловые системы хранилищ

!!! note

    По умолчанию Bazzite автоматически монтирует дополнительные диски, отформатированные в Ext4 или BTRFS.

**BTRFS - файловая система по умолчанию и рекомендуемый вариант для Bazzite**. Все дополнительные диски, на которых вы планируете играть, следует **предварительно скопировать в резервную копию и переформатировать в Ext4 или BTRFS. При этом диск потеряет все данные**. Вы можете использовать [**GNOME Disks для подходящего форматирования дисков на свой риск**](../Advanced/Auto-Mounting_Secondary_Drives.md).

!!! warning "При переформатировании все данные на диске будут потеряны."

### Неподдерживаемые файловые системы для дополнительных дисков { #unsupported-filesystems-for-secondary-drives }

!!! warning

    NTFS и exFAT/FAT32 НЕ ПОДДЕРЖИВАЮТСЯ. В Linux эти файловые системы могут со временем привести к ПОВРЕЖДЕНИЮ ДАННЫХ и/или не поддерживают функции, нужные для Proton/WINE. НЕ используйте их!
    В WinBTRFS все еще есть ОШИБКИ, а система прав и владельцев файлов в Windows сильно отличается от Linux. Нет гарантии, что позже вы не столкнетесь с проблемами и/или потерей данных.
    
    Все это значит, что надежной кроссплатформенной файловой системы для совместного использования в Windows и Linux, к сожалению, нет.

!!! warning "При переформатировании все данные на диске будут потеряны."
    
!!! info
    
    Чтобы отключить предупреждение об NTFS, выполните `ujust _disable-ntfs-service`. **ДЕЛАЙТЕ ЭТО ТОЛЬКО ЕСЛИ ПОНИМАЕТЕ, ЧТО ДЕЛАЕТЕ. ЭТО НЕ ПРЕДОТВРАТИТ ПОТЕРЮ ДАННЫХ, А ТОЛЬКО ОТКЛЮЧИТ ПРЕДУПРЕЖДЕНИЕ.**


#### NTFS

Если вы переходите с Windows и планируете играть с дополнительного диска, на котором уже установлены игры, вынуждены сообщить: файловая система NTFS **не поддерживается** для игр на ПК в Bazzite.

Запуск игр с NTFS вызывает разные проблемы, включая **полный отказ игр запускаться**, а со временем приведет к **повреждению данных** и **безвозвратной потере данных**!

#### exFAT и FAT32

FAT32 и exFAT **не поддерживаются**. Обе файловые системы **не поддерживают символические ссылки**, которые нужны для правильной работы префиксов Proton. Однако в некоторых сценариях карта microSD, отформатированная в exFAT, _может работать_, но такой вариант не поддерживается, поскольку сопровождающие Bazzite не планируют адаптировать систему под него.

Кроме того, семейство файловых систем FAT не относится к [журналируемым файловым системам](https://en.wikipedia.org/wiki/Journaling_file_system). Это значит, что потеря или повреждение данных на FAT вероятнее, а восстановление намного сложнее. Поэтому Bazzite также советует не хранить важные данные на файловых системах FAT без резервных копий.

### Совместное использование игр с двойной загрузкой Windows

Установите неофициальный драйвер [WinBtrfs](https://github.com/maharmstone/btrfs) в вашей установке Windows **на свой риск**. Перед установкой драйвера в Windows обязательно прочитайте документацию проекта.
