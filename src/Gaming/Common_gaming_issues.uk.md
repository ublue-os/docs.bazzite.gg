# Поширені проблеми з іграми

## Нативна версія для Linux чи версія для Windows { #native-linux-port-versus-windows-version }

У деяких версіях для Linux може бракувати функцій або продуктивність може бути гіршою, ніж у версії для Windows, запущеної через Proton. Однак бувають випадки, коли нативна версія — єдиний варіант, і навіть кращий.

Якщо нативна гра для Linux не запускається, спробуйте примусово ввімкнути шар сумісності **Legacy Runtime**: у **Steam** відкрийте **Властивості** гри (Properties) → **Сумісність** (Compatibility), увімкніть «**Примусово використовувати певний інструмент сумісності Steam Play**» (Force the use of a specific Steam Play compatibility tool) і виберіть його у спадному меню.

!!! warning "Використовуйте **лише** версію Counter-Strike 2 для Linux (тобто ВИМКНІТЬ **Примусово використовувати певний інструмент сумісності Steam Play**). За запуск CS2 через Proton можна отримати VAC-бан."

## Denuvo Anti-Tamper DRM блокує ігри { #denuvo-anti-tamper-drm-locking-games }

Ігри із захистом Denuvo Anti-Tamper DRM сприймають зміну версії Proton як активацію гри на іншому обладнанні. Через це гру можуть тимчасово заблокувати, якщо змінити версію Proton більше ніж 5 разів за 24 години. У такому разі доведеться почекати 24 години, перш ніж гру знову можна буде запустити.

## Помилки зі звуком і користувацьким вмістом у рушії Source 1 { #source-1-engine-audio-and-custom-content-bugs }

!!! note

    Це стосується лише окремих ігор на [рушії Source](https://www.pcgamingwiki.com/wiki/Engine:Source).

!!! attention

    **Не** застосовуйте це обхідне рішення, доки не зіткнетеся з проблемами зі звуком або з описаною нижче ситуацією в _Left 4 Dead 2_.

Пропадають репліки персонажів або не завантажується користувацький вміст в іграх на Source? SELinux блокує декодування MP3 та інші проміжні бібліотеки, бо вони [**виконують код у пам'яті купи**](https://github.com/ValveSoftware/steam-for-linux/issues/43).

Підтверджено, що це також спричиняє проблеми з приєднанням до користувацьких мап і їх створенням у _Left 4 Dead 2_.

### Як виправити проблеми зі звуком і користувацьким вмістом { #the-fix-for-audiocustom-content-issues }

!!! warning

    Налаштування SELinux призначене для досвідчених користувачів. Якщо робити це безвідповідально, можна зламати інші компоненти системи й послабити безпеку пристрою.

Щоб виправити описані проблеми зі звуком і користувацьким вмістом, можна створити й встановити модуль, який дозволить іграм на Source проходити через SELinux, на основі попередніх журналів безпеки, спричинених `hl2_linux`.

Робіть це **на власний ризик**!

=== "Створити й встановити модуль політики"

    ```bash
    sudo -i
    cd /tmp
    ausearch -c 'hl2_linux' --raw | audit2allow -M my-hl2linux
    semodule -X 300 -i my-hl2linux.pp
    ```
    Перезавантажте пристрій і перевірте, чи проблеми ще виникають.

=== "Вимкнути модуль політики"

    ```bash
    semodule -X 300 -d my-hl2linux
    ```

=== "Видалити модуль політики"

    ```bash
    semodule -X 300 -r my-hl2linux
    ```
    За бажанням можна видалити файл `.pp` у `/root/`.

## Ігри Steam не запускаються { #steam-games-not-launching }

Ігри Steam можуть не запускатися з різних причин. Нижче перелічено поширені причини, через які ігри ніби одразу закриваються (тобто стан змінюється із **Запущено** (Running) на **Грати** (Play) одразу або за короткий час).

### `gamemoderun` { #gamemoderun }

!!! note

      Не плутайте з **ігровим режимом** (Gaming Mode) в образах Deck. (Feral) GameMode — це бібліотека, через яку ігри можуть просити ОС про оптимізації.

Ігри не запускатимуться, якщо додати до параметрів запуску `gamemoderun %command%`, що часто трапляється на ProtonDB.

Приберіть це з параметрів запуску з трьох причин: <small>_з п'ятьох трьом доведеться заплатити..._</small>

-   GameMode не встановлено і не підтримується в Bazzite
-   На сучасному обладнанні він зазвичай нічого корисного не робить
-   ... а іноді навіть погіршує продуктивність

Він може запрацювати, якщо накласти пакунок `gamemode`, але це **НЕ** підтримується.

### Проблеми з правами доступу на дисках NTFS: { #ntfs-formatted-drive-permission-issues }

Переконайтеся, що ваші ігри **не** на розділі NTFS (Windows). Докладніше — [**тут**](./Hardware_compatibility_for_gaming.md#unsupported-filesystems-for-secondary-drives).

### Особливості WINE з кількома користувачами: { #multi-user-wine-quirks }

!!! note

    Bazzite-Deck не підтримує кількох облікових записів користувачів Linux, тож ця інформація стосується лише Desktop-версії Bazzite.

Іноді ігри Steam взагалі відмовляються запускатися в другому обліковому записі користувача. Причина може бути у власнику файлів префікса WINE. У файлі ` ~/.local/share/Steam/logs/console-linux.txt` у другому обліковому записі ви можете побачити помилку на кшталт:

```
wineserver: /SteamLibrary/steamapps/compatdata/377160/pfx is not owned by you
```

Це можна виправити, створивши окрему теку бібліотеки Steam для даних префіксів Proton і символічні посилання (_symlink_) на інші теки (наприклад, на спільні дані ігор).

```console
USER2@bazzite: /mnt/ExtraStuff/USER2SteamLibrary/steamapps$ ls -la
total 32
drwxrwxr-x. 3 USER2 steamplayers 4096 Jan 29 15:19 .
drwxrwsr-x. 3 USER2 steamplayers 4096 Jan 29 16:13 ..
-rwxr-xr-x. 1 USER2 USER2         2287 Jan 29 15:19 appmanifest_377160.acf
lrwxrwxrwx. 1 USER2 USER2           51 Jan 29 15:10 common -> /mnt/ExtraStuff/USER1SteamLibrary/steamapps/common/
drwxr-xr-x. 3 USER2 USER2         4096 Jan 29 15:13 compatdata
lrwxrwxrwx. 1 USER2 USER2           56 Jan 29 15:12 shadercache -> /mnt/ExtraStuff/USER1SteamLibrary/steamapps/shadercache/
lrwxrwxrwx. 1 USER2 USER2           49 Jan 29 15:12 temp
lrwxrwxrwx. 1 USER2 USER2           53 Jan 29 15:12 workshop
```

Так само скопіюйте або зробіть символічні посилання на файли appmanifest з кожної бібліотеки, щоб ігри правильно відображалися в кожній бібліотеці Steam.

## Збирання журналів Proton { #gathering-proton-log-files }

Якщо виникають проблеми із запуском гри через Proton, журнали Proton можна отримати так:

1.  Додайте [змінну середовища](./launch-options-env-variables.md) `PROTON_LOG=1 %command%` у **параметри запуску** Steam або у відповідне поле в інших лаунчерах:
2.  Запустіть гру
3.  У домашній теці має з'явитися файл журналу з назвою за ідентифікатором гри. Шукайте `~/steam-{App ID}.log`, де `{App ID}` — набір цифр

Цей файл журналу можна використати, щоб попросити про допомогу або надіслати звіт про помилку до Valve.
