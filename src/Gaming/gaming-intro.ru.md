# Введение в игры на Bazzite

## Смена парадигмы

Игры на Linux как реальная альтернатива Windows - сравнительно новая парадигма. Большинство игр, доступных только для Windows, могут работать на Bazzite при использовании современного оборудования. Шероховатости все еще встречаются, но игры на Linux на подходящем оборудовании дают и преимущества, например более стабильное время кадра по сравнению с Windows.

### Игры Steam { #steam-games }

Steam - рекомендуемый способ играть в PC-игры на Bazzite, так как он поставляется со слоем совместимости [**Proton**](/General/terms#software). Большинство одиночных PC-игр должны запускаться без дополнительных настроек, хотя бывают случаи, когда купленная и установленная через Steam игра не запускается сразу.

Некоторые новые сетевые многопользовательские игры требуют более глубокого доступа к оборудованию компьютера и драйверам Windows для работы античита. На Linux такой доступ может быть заблокирован, поэтому эти игры будут доступны только в Windows.

### Игры не из Steam

<small>_На этом мы охватили в Bazzite Docs всю наблюдаемую вселенную, от Steam-игр... до игр не из Steam. Что и требовалось доказать._</small>

Bazzite также может запускать игры вне Steam с помощью **Lutris** - фронтенда для запуска видеоигр и другого ПО через Proton/WINE. [**Faugus Launcher**](https://flathub.org/en/apps/io.github.Faugus.faugus-launcher) - альтернатива Lutris, доступная в магазине приложений Bazaar. Он может быть удобнее благодаря более простому дизайну. [**Heroic Games Launcher**](https://flathub.org/apps/com.heroicgameslauncher.hgl) рекомендуется вместо Lutris для игр, купленных в Epic Games Launcher, GOG и Amazon Games Launcher.

Игры, установленные из Microsoft Store, **не** запускаются, если не использовать клиент Xbox Cloud Gaming, например [**Greenlight**](https://github.com/unknownskl/greenlight), для которого большинству игр нужна подписка Game Pass Ultimate. В Fortnite этим способом также можно играть **без** подписки Game Pass. Также есть [**отдельные игры Game Pass, доступные в Battle.net**](https://us.support.blizzard.com/en/help/article/000367382), которые можно запускать через Lutris.

Эмуляторы консолей можно установить из Bazaar или через проекты вроде [**Retrodeck**](https://flathub.org/en/apps/net.retrodeck.retrodeck) и [**Emudeck**](https://www.emudeck.com/) (доступен в приложении Bazzite Portal).

## Полезные внешние ресурсы

-   [**ProtonDB**](https://www.protondb.com/explore) - отчеты пользователей о совместимости игр на Linux
-   [**Are We Anti-Cheat Yet?**](https://areweanticheatyet.com/) - список популярных игр с античитом и сведения о поддержке Linux
-   [**Linux Gaming Wiki**](https://linux-gaming.kwindu.eu/index.php?title=Main_Page) - введение в игры на Linux с полезными ссылками
-   [**PC Gaming Wiki**](https://www.pcgamingwiki.com/wiki/Home) - общая информация, обходные решения и улучшения для PC-игр
-   [**General Emulation Wiki**](https://emulation.gametechwiki.com/index.php/Main_Page) - ресурсы по эмуляции
-   [**Linux VR Adventures Wiki**](https://lvra.gitlab.io/) - общая информация о запуске VR-игр на Linux
-   [**Linux VR Adventure Database**](https://db.vronlinux.org/) - отчеты пользователей о совместимости игр виртуальной реальности (VR) на Linux
