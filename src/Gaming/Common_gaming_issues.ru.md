# Частые проблемы с играми

## Нативный порт Linux или версия Windows

У некоторых портов для Linux может не хватать функций, либо они могут работать хуже, чем версия для Windows, запущенная через Proton. Но бывают ситуации, когда использовать только нативный порт - единственный вариант, и иногда это даже предпочтительно.

Если нативная игра для Linux не запускается, попробуйте принудительно включить слой совместимости **Legacy Runtime**: включите "**Force the use of a specific Steam Play compatibility tool**" в **Steam** → **Properties** игры → **Compatibility** и выберите его в раскрывающемся меню.

!!! warning "Используйте **только** нативную Linux-версию Counter Strike 2, то есть ОТКЛЮЧИТЕ **Force the use of a specific Steam Play compatibility tool**. За запуск CS2 через Proton можно получить VAC-бан."

## Блокировка игр с Denuvo Anti-Tamper DRM

Игры с Denuvo Anti-Tamper DRM считают смену версии Proton активацией игры на другом оборудовании. Если сменить версию Proton больше 5 раз за 24 часа, игра может временно заблокировать доступ. В таком случае нужно подождать 24 часа, прежде чем вы снова сможете запустить игру.

## Ошибки со звуком и пользовательским содержимым в Source 1 Engine

!!! note

    Это относится только к отдельным играм на [движке Source](https://www.pcgamingwiki.com/wiki/Engine:Source).

!!! attention

    **Не** используйте этот обходной способ, пока не столкнетесь с проблемами звука или с описанной ниже ситуацией в _Left 4 Dead 2_.

В играх Source пропали голосовые реплики или не загружается пользовательское содержимое? SELinux блокирует декодирование MP3 и другое промежуточное ПО, потому что оно [**выполняет код из памяти кучи**](https://github.com/ValveSoftware/steam-for-linux/issues/43).

Также подтверждено, что это вызывает проблемы при подключении к пользовательским картам и их размещении в _Left 4 Dead 2_.

### Исправление проблем со звуком и пользовательским содержимым:

!!! warning

    Настройка SELinux рассчитана на опытных пользователей. При неосторожном использовании она может сломать другие компоненты системы и ослабить безопасность устройства.

Чтобы исправить упомянутые проблемы со звуком и пользовательским содержимым, можно создать и установить модуль, который разрешит играм Source нужные действия в SELinux на основе предыдущих журналов безопасности, вызванных `hl2_linux`.

Продолжайте **на свой страх и риск**!

=== "Create and install the policy module"

    ```bash
    sudo -i
    cd /tmp
    ausearch -c 'hl2_linux' --raw | audit2allow -M my-hl2linux
    semodule -X 300 -i my-hl2linux.pp
    ```
    Перезагрузите устройство и проверьте, сталкиваетесь ли вы с упомянутыми проблемами.

=== "Disable the policy module"

    ```bash
    semodule -X 300 -d my-hl2linux
    ```

=== "Remove the policy module"

    ```bash
    semodule -X 300 -r my-hl2linux
    ```
    При желании можно удалить файл `.pp` из `/root/`.

## Игры Steam не запускаются

Игры Steam могут не запускаться по разным причинам. Ниже перечислены частые причины, из-за которых игры выглядят так, будто закрываются сразу: статус меняется с **Running** на **Play** сразу или через короткое время.

### `gamemoderun`

!!! note

      Не путайте с **Gaming Mode** на образах Deck. (Feral) GameMode - библиотека, которая позволяет играм запрашивать оптимизации у ОС.

Игры не запустятся, если добавить `gamemoderun %command%` в параметры запуска. Такой совет часто встречается на ProtonDB.

Удалите это из параметров запуска по трем причинам:  <small>_из пяти человек трое должны заплатить цену..._</small>

-   GameMode не установлен и не поддерживается в Bazzite
-   Обычно он не дает ничего полезного на современном оборудовании
-   ... а в некоторых случаях может даже ухудшить производительность

Это может сработать, если наложить пакет `gamemode`, но такой вариант **НЕ** поддерживается.

### Проблемы с правами на диске, отформатированном в NTFS:

Убедитесь, что игры **не** находятся на разделе NTFS (Windows). Дополнительную информацию можно найти [**здесь**](./Hardware_compatibility_for_gaming.md#unsupported-filesystems-for-secondary-drives).

### Особенности WINE при нескольких пользователях:

!!! note

    Bazzite-Deck не поддерживает несколько учетных записей Linux. Эта информация относится только к Desktop-редакции Bazzite.

Иногда игры Steam полностью отказываются запускаться во второй учетной записи. Причиной могут быть права владельца файлов префикса WINE. Во второй учетной записи в ` ~/.local/share/Steam/logs/console-linux.txt` может появиться такая ошибка:

```
wineserver: /SteamLibrary/steamapps/compatdata/377160/pfx is not owned by you
```

Это можно исправить так: создайте отдельную папку библиотеки Steam для данных префикса Proton и создайте символическую ссылку (_symlink_) для остальных папок, например с общими игровыми данными.

```console
USER2@bazzite: /mnt/ExtraStuff/USER2SteamLibrary/steamapps$ ls -la
total 32
drwxrwxr-x. 3 USER2 steamplayers 4096 Jan 29 15:19 .
drwxrwsr-x. 3 USER2 steamplayers 4096 Jan 29 16:13 ..
-rwxr-xr-x. 1 USER2 USER2         2287 Jan 29 15:19 appmanifest_377160.acf
lrwxrwxrwx. 1 USER2 USER2           51 Jan 29 15:10 common -> /mnt/ExtraStuff/USER1SteamLibrary/steamapps/common/
drwxr-xr-x. 3 USER2 USER2         4096 Jan 29 15:13 compatdata
lrwxrwxrwx. 1 USER2 USER2           56 Jan 29 15:12 shadercache -> /mnt/ExtraStuff/USER1SteamLibrary/steamapps/shadercache/
lrwxrwxrwx. 1 USER2 USER2           49 Jan 29 15:12 temp
lrwxrwxrwx. 1 USER2 USER2           53 Jan 29 15:12 workshop
```

Аналогично скопируйте файлы appmanifest из каждой библиотеки или создайте для них символические ссылки, чтобы игры корректно отображались в каждой библиотеке Steam.

## Сбор файлов журналов Proton

Если у вас возникают проблемы с запуском игры через Proton, выполните следующие шаги, чтобы получить файлы журналов Proton.

1.  Добавьте [переменную окружения](/Gaming/launch-options-env-variables) `PROTON_LOG=1 %command%` в **launch options** Steam или в соответствующее поле другого лаунчера:
2.  Запустите игру
3.  В домашнем каталоге должен появиться файл журнала, названный по номеру идентификатора приложения игры. Ищите `~/steam-{App ID}.log`, где `{App ID}` - набор цифр

Этот файл журнала можно использовать при обращении за поддержкой или для отправки отчета об ошибке в Valve.
