# Вступ до ігор на Bazzite

## Зміна парадигми { #paradigm-shift }

Те, що ігри в Linux стали справжнім конкурентом Windows, — відносно нова реальність. Більшість ігор, доступних лише для Windows, на сучасному обладнанні працюють і в Bazzite. Деякі шорсткості ще лишаються, але на відповідному обладнанні ігри в Linux мають і переваги, наприклад стабільніший час кадру, ніж у Windows.

### Ігри зі Steam { #steam-games }

Steam — рекомендований спосіб грати в ігри для ПК на Bazzite, бо в нього вбудовано шар сумісності [**Proton**](../General/terms.md#software). Більшість одиночних ігор для ПК мають запускатися без жодних налаштувань, хоча трапляються випадки, коли куплена й встановлена через Steam гра одразу не запускається.

Деяким новим мережевим іграм потрібен глибший доступ до обладнання комп'ютера і драйверів Windows, щоб працювало їхнє античит-ПЗ, яке в Linux може бути заблоковане. Тобто в такі ігри можна грати лише у Windows.

### Ігри не зі Steam { #non-steam-games }

<small>_Отже, ми вмістили в документацію Bazzite усе в спостережуваному Всесвіті — від ігор зі Steam... до ігор не зі Steam. Що й треба було довести._</small>

Bazzite також може запускати ігри поза Steam за допомогою **Lutris** — графічного інтерфейсу для запуску ігор та інших програм через Proton/WINE. [**Faugus Launcher**](https://flathub.org/en/apps/io.github.Faugus.faugus-launcher) — альтернатива Lutris, доступна в магазині застосунків Bazaar; через простіший дизайн вона може бути зручнішою. Для ігор, куплених в Epic Games Launcher, GOG та Amazon Games Launcher, замість Lutris рекомендуємо [**Heroic Games Launcher**](https://flathub.org/apps/com.heroicgameslauncher.hgl).

Ігри, встановлені з Microsoft Store, **не** запускаються, якщо не використовувати клієнт Xbox Cloud Gaming, як-от [**Greenlight**](https://github.com/unknownskl/greenlight), для якого для більшості ігор потрібна підписка Game Pass Ultimate. У Fortnite так само можна грати **без** підписки Game Pass. Також [**деякі ігри Game Pass доступні в Battle.net**](https://us.support.blizzard.com/en/help/article/000367382), і їх можна запускати через Lutris.

Емулятори консолей можна встановити з Bazaar або через проєкти на кшталт [**Retrodeck**](https://flathub.org/en/apps/net.retrodeck.retrodeck) чи [**Emudeck**](https://www.emudeck.com/) (доступний у застосунку Bazzite Portal).

## Корисні зовнішні ресурси { #useful-external-resources }

-   [**ProtonDB**](https://www.protondb.com/explore) — звіти користувачів про сумісність ігор з Linux
-   [**Are We Anti-Cheat Yet?**](https://areweanticheatyet.com/) — список популярних ігор з античитом і чи підтримують вони Linux
-   [**Linux Gaming Wiki**](https://linux-gaming.kwindu.eu/index.php?title=Main_Page) — вступ до ігор у Linux з корисними посиланнями
-   [**PC Gaming Wiki**](https://www.pcgamingwiki.com/wiki/Home) — загальна інформація, способи обійти проблеми й покращення для ігор на ПК
-   [**General Emulation Wiki**](https://emulation.gametechwiki.com/index.php/Main_Page) — ресурси про емуляцію
-   [**Linux VR Adventures Wiki**](https://lvra.gitlab.io/) — загальна інформація про запуск VR-ігор у Linux
-   [**Linux VR Adventure Database**](https://db.vronlinux.org/) — звіти користувачів про сумісність ігор віртуальної реальності (VR) з Linux
