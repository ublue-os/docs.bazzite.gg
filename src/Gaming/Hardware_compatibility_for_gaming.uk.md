# Сумісність обладнання для ігор у Linux

## Мінімальні системні вимоги { #minimum-system-requirements }

- **Прошивка**: UEFI (завантаження CSM/Legacy [**НЕ ПІДТРИМУЄТЬСЯ**](../General/FAQ.md#does-bazzite-support-csmlegacy-boot))
- **Процесор (CPU)** : чотириядерний процесор від 2 ГГц або кращий
  - **Архітектура**: x86-64
- **Оперативна пам'ять (RAM)**: 8 ГБ
- **Графіка**: відеокарта з підтримкою Vulkan 1.3 або новішої версії
- **Сховище**: 50 ГБ вільного місця на внутрішньому **твердотільному накопичувачі (SSD)**
  - **Рекомендоване сховище**: 120 ГБ вільного місця на внутрішньому **твердотільному накопичувачі (SSD)**
  - Наявні диски **мають** бути розмічені як **GPT**. Спроба встановити Bazzite на диск із розміткою MBR (Master Boot Record) завершиться невдачею.
    - Microsoft пропонує [інструмент для перетворення наявних інсталяцій Windows на GPT](https://learn.microsoft.com/en-us/windows/deployment/mbr-to-gpt).
    !!! warning "Перш ніж виконувати будь-які операції з диском, зробіть резервну копію всіх важливих особистих файлів!"
  - **Зовнішні та додаткові диски**: усі диски мають бути відформатовані в **BTRFS (твердотільні накопичувачі [SSD])** або **Ext4 (жорсткі диски [HDD])**. _Зробіть резервну копію файлів і переформатуйте диски після встановлення._
  > Докладніше — [тут](#unsupported-filesystems-for-secondary-drives).
- **Мережа**: стабільне підключення до інтернету без обмежень трафіку (_для встановлення не потрібне_)

!!! note

    Деякі периферійні пристрої, залежно від виробника, **не** сумісні з Linux, а отже, і з Bazzite. Для **Wi-Fi-адаптерів** є [список USB Wi-Fi-адаптерів, **про які відомо, що вони сумісні**](https://github.com/morrownr/USB-WiFi/blob/main/home/USB_WiFi_Adapters_that_are_supported_with_Linux_in-kernel_drivers.md).

>[**Сайт Hardware for Linux**](https://linux-hardware.org/?view=computers) добре показує, наскільки обладнання різних виробників підтримується в настільному Linux.

### Вимоги ігрового режиму Steam { #steam-gaming-mode-requirements }

!!! note

    Ці вимоги стосуються лише [образів Bazzite-Deck](../Handheld_and_HTPC_edition/Steam_Gaming_Mode.md), які входять до всіх ISO-образів Bazzite для портативних пристроїв, і схожі на вимоги [SteamOS](https://store.steampowered.com/steamos/)

    - Також підтримуються вбудовані відеоядра 600M/700M

- Відеокарти Nvidia підтримуються зі [**значними застереженнями**](../Handheld_and_HTPC_edition/quirks.md#nvidia-gpu-exclusive-issues-with-steam-gaming-mode) порівняно з обладнанням AMD. На жаль, це не залежить від мейнтейнерів Bazzite.
- Потрібен обліковий запис [**Steam**](https://store.steampowered.com/)
  - Якщо облікового запису ще немає, його можна створити після встановлення

## Відеокарта з підтримкою Vulkan { #vulkan-compatible-gpu }

!!! attention

    Ігри в Linux значною мірою залежать від того, чи підтримує обладнання [Vulkan](../General/terms.md#software).

### Як дізнатися версію Vulkan своєї відеокарти { #viewing-your-gpus-vulkan-version }

Якщо ваш пристрій має стару або слабку відеокарту, яка підтримує **Vulkan 1.1 або 1.2**, але не **Vulkan 1.3 чи новіший**, використовуйте Proton-CachyOS з DXVK-Sarek, як описано нижче. Щоб дізнатися, яку версію Vulkan підтримує ваша відеокарта, введіть у **терміналі**:

```bash
vulkaninfo | grep 'Instance Version'
```

![Vulkan Command](https://github.com/user-attachments/assets/ccca14ca-3001-4aa6-bf47-e0dcbdb73936)

- Якщо в рядку `Vulkan Instance Version:` виводиться версія, нижча за `1.3`, або команда взагалі не працює, виникатимуть проблеми, зокрема ігри, у які неможливо грати, і нижча продуктивність.

- Дуже старим пристроям, можливо, доведеться вдатися до трансляції OpenGL, яка працює гірше, має графічні проблеми тощо.

> Якщо ваше обладнання підтримує лише Vulkan 1.1/1.2, спробуйте [**DXVK-Sarek**](https://github.com/pythonlover02/DXVK-Sarek). Він офіційно підтримується в [Proton-CachyOS](https://github.com/CachyOS/proton-cachyos) і вмикається [змінною середовища](./launch-options-env-variables.md) `PROTON_DXVK_SAREK=1`. Однак не використовуйте цей параметр в іграх з античитом або в мережевих іграх.

!!! info "[Proton-CachyOS](https://github.com/CachyOS/proton-cachyos) можна встановити за допомогою ProtonPlus або ProtonUp-Qt."

### Відеокарти без підтримки Vulkan { #gpus-without-vulkan-support }

Якщо ваша відеокарта зовсім не підтримує Vulkan, використовуйте цей **параметр запуску для всіх ігор, що запускаються через Proton**:

```bash
PROTON_USE_WINED3D=1 %command%
```

Тоді замість Vulkan використовуватиметься трансляція в OpenGL.

## Файлові системи сховища { #storage-filesystems }

!!! note

    За замовчуванням Bazzite автоматично монтує додаткові диски, відформатовані в Ext4 або BTRFS.

**BTRFS — стандартна й рекомендована файлова система для Bazzite**. З усіх додаткових дисків, на яких ви плануєте грати, слід **зробити резервну копію, а потім переформатувати їх в Ext4 або BTRFS, але під час цієї операції всі дані на диску буде втрачено**. Відформатувати диски належним чином можна за допомогою [**«Дисків» GNOME на власний ризик**](../Advanced/Auto-Mounting_Secondary_Drives.md).

!!! warning "Під час переформатування всі дані на диску буде втрачено."

### Непідтримувані файлові системи для додаткових дисків { #unsupported-filesystems-for-secondary-drives }

!!! warning

    NTFS і exFAT/FAT32 НЕ ПІДТРИМУЮТЬСЯ. У Linux ці файлові системи рано чи пізно ПОШКОДЯТЬ ДАНІ та/або не підтримують функцій, потрібних для Proton/WINE. НЕ використовуйте їх!
    У WinBTRFS досі є ПОМИЛКИ, а система прав доступу і власників файлів у Windows дуже відрізняється від Linux, тож немає жодної гарантії, що згодом ви не зіткнетеся з проблемами та/або втратою даних.
    
    Усе це означає, що, на жаль, немає надійної кросплатформної файлової системи, яку можна було б спільно використовувати у Windows і Linux.

!!! warning "Під час переформатування всі дані на диску буде втрачено."
    
!!! info
    
    Щоб вимкнути набридливе попередження про NTFS, виконайте `ujust _disable-ntfs-service`. **РОБІТЬ ЦЕ, ЛИШЕ ЯКЩО ЗНАЄТЕ, ЩО РОБИТЕ. ЦЕ НЕ ЗАПОБІГАЄ ВТРАТІ ДАНИХ, А ЛИШЕ ВИМИКАЄ ПОПЕРЕДЖЕННЯ.**


#### NTFS { #ntfs }

Якщо ви переходите з Windows і плануєте грати з додаткового диска, на якому вже встановлено ігри, мусимо вас засмутити: для ігор на ПК у Bazzite файлова система NTFS **не підтримується**.

Запуск ігор з NTFS спричиняє різні проблеми, зокрема **ігри взагалі не запускаються**, а зрештою це призведе до **пошкодження даних** і **безповоротної втрати даних**!

#### exFAT і FAT32 { #exfat-and-fat32 }

FAT32 і exFAT **не підтримуються**. Обидві файлові системи **не підтримують символічні посилання**, які потрібні для правильної роботи префіксів Proton. Іноді microSD-картка, відформатована в exFAT, _може працювати_, але цей спосіб не підтримується, і мейнтейнери Bazzite не планують його підтримувати.

Крім того, файлові системи сімейства FAT не є [журнальованими файловими системами](https://uk.wikipedia.org/wiki/Журнальована_файлова_система). Це означає, що на FAT втрата або пошкодження даних імовірніші, а відновити їх значно-значно важче. Тому Bazzite також радить не зберігати важливі дані без резервних копій на файлових системах FAT.
