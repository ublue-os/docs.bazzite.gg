# Портативні пристрої Ayn

!!! disclaimer

    Ця вікі може містити застарілу інформацію.

## Загальна інформація й налаштування { #general-information-tweaks }

- RGB-підсвічування можна налаштувати в ігровому режимі Steam у **Налаштування → Контролер → Калібрування та розширені налаштування → Налаштування індикаторів** (Settings → Controller → Calibration & Advanced Settings → LED Settings) або в OpenGamepadUI, якщо він доступний.
  - Щоб налаштування RGB працювало, можливо, доведеться вибрати емуляцію контролера DualShock.
- Масштаб інтерфейсу можна змінити в налаштуваннях екрана.
- Обмеження заряду можна задати в режимі робочого столу.

## Загальні проблеми { #general-issues }

- Ігри іноді можуть за замовчуванням запускатися з роздільністю 800p.
  - Можна вручну змінити роздільність для кожної гри у **Властивостях** гри → **Загальне** → **Максимальна роздільність гри** (Properties → General → Maximum Game Resolution) на «Вбудована» (Native) або іншу, вищу.

### Відомі проблеми { #known-issues_1 }

- Драйвер звуку зараз не працює.
  - Вбудованого звуку немає ні в ігровому режимі, ні в режимі робочого столу.
  - Повідомляють, що зовнішній звук має низьку якість.
- У режимі робочого столу на образах з KDE неправильний поворот екрана.
- У режимі робочого столу може не працювати введення мишею.
