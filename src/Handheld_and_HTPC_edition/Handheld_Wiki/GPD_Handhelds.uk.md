# Портативні пристрої GPD

!!! disclaimer

    Ця вікі може містити застарілу інформацію.

## Загальна інформація й налаштування { #general-information-tweaks }

- RGB-підсвічування можна налаштувати в ігровому режимі Steam або за допомогою плагіна Decky Huesync.
- На пристроях GPD зазвичай є фізичний перемикач, який вмикає окремий режим робочого столу/миші.

---

## Загальні проблеми { #general-issues }

- На пристроях із Ryzen 7 6800U або його похідними, щоб працював сон і вихід із нього, потрібно вимкнути сканер відбитків пальців.
- На пристроях із Ryzen 7 7840U або його похідними (2023–2025) сон і вихід із нього працюють частково: пристрій примусово переходить у гібернацію, коли батарея розрядиться на 5 %. За цією проблемою можна стежити [тут](https://gitlab.freedesktop.org/drm/amd/-/issues/3154).
- Задні кнопки, можливо, доведеться перепризначити вручну, перш ніж ними можна буде користуватися.
  - Перепризначте задні кнопки вручну в QAM, за це тепер відповідає [OpenGamepadUI.](https://github.com/ShadowBlip/OpenGamepadUI)
- Ігри іноді за замовчуванням запускаються з роздільністю 800p.
  - Змініть роздільність вручну для кожної гри у **Властивостях** гри → **Загальне** → **Максимальна роздільність гри** (Properties → General → Maximum Game Resolution) на **Вбудована** (Native) або іншу, вищу.

## GPD Win Max 2 { #gpd-win-max-2 }

![placeholder_gpdwinmax2|407x312, 100%](../../img/GPD_Win_Max_2.png)

### Необов'язкові налаштування { #optional-tweaks_1 }

- Рекомендовані налаштування **Екрана** (Display) в ігровому режимі Steam:
  - **Використовувати стандартну температуру кольору** (Use Native Color Temperature): увімкнено

> Див. [Загальна інформація й налаштування](#general-information-tweaks)

### Відомі проблеми { #known-issues_1 }

- Якщо ОС встановлено на SSD m.2 2230 у додатковому слоті, можуть бути проблеми зі сном.
  - ОС варто встановлювати лише на основний внутрішній SSD.
- Гіроскоп не працює.
