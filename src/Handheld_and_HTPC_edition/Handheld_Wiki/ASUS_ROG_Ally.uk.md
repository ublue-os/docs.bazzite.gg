# Портативні пристрої ASUS

!!! disclaimer

    Ця вікі може містити застарілу інформацію.

## ASUS ROG Ally / ASUS ROG Ally X { #asus-rog-ally-asus-rog-ally-x }

![ally|603x500, 100%](../../img/ally.png)

### Загальні примітки { #general-notes }

- Якщо утримувати кнопку Armoury Crate (збоку), можна перейти в режим миші

### Необов'язкові налаштування { #optional-tweaks }

- RGB-підсвічування можна налаштувати в ігровому режимі Steam за допомогою плагінів
  - Щоб налаштування RGB працювало, можливо, доведеться вибрати емуляцію контролера DualShock.

### Відомі проблеми { #known-issues }

- Після підключення або відключення живлення TDP іноді «застрягає».
  - Це трапляється, якщо від'єднати зарядний пристрій у режимі очікування.
  - Обхідне рішення — під'єднувати й від'єднувати зарядний пристрій не в режимі очікування.
- Звук тихий
  - На ROG Ally є два звукові пристрої:
    - **Family 17h/19h/1ah HD Audio Controller**
    - **ROG Ally**
  - Вони впливають на гучність один одного, тому гучність на обох має бути однакова.
- Мікрофон звучить спотворено
  - Може допомогти встановити гучність мікрофона (вхідного сигналу) у налаштуваннях на 10–15 %
  - Також, можливо, доведеться вибрати в налаштуваннях Discord профіль вхідного сигналу **Noise Cancellation** (шумозаглушення).
- Параметр «Auto UMA» в UEFI/BIOS може спричиняти збої в деяких іграх.
  - Встановіть у BIOS обсяг VRAM **4 ГБ** або **8 ГБ**.
- Світлодіодний індикатор за замовчуванням світиться з максимальною яскравістю, і змінити її можна лише у Windows.
  - На жаль, це залежить від прошивки.
  - Ця проблема може бути й під час заряджання та сну.
- Ally **не** підтримує утримання кнопок Steam і QAM.
  - Комбінації (chords) введення Steam за замовчуванням можуть не працювати.
  - Як обхідне рішення можна поміняти місцями кнопки Start і Select.
- Сон може не працювати, якщо вимкнено SMT
- Драйвер сканера відбитків пальців може не працювати.
- У сховищі можуть показуватися диски-дублікати.
  - Це лише помилка відображення, **не** намагайтеся форматувати такий диск!
- Якщо ввімкнути анімацію пробудження під час виходу зі сну, пристрій може поводитися непередбачувано.
  - Коли ця помилка спрацьовує, верхня й нижня панелі Steam можуть зникати.
