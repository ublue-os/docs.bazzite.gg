# Порівняння Bazzite і SteamOS

## Що таке SteamOS? { #what-is-steamos }

**SteamOS** — операційна система, спочатку розроблена для Steam Deck. SteamOS — це ОС для клієнта Steam, яка також має базове робоче середовище **KDE Plasma**. У ньому можна, наприклад, встановлювати моди й емулятори, але для повсякденної роботи за комп'ютером його можливостей може бути замало.

## Що таке Bazzite? { #what-is-bazzite }

Bazzite — ігрова операційна система Linux, яку розвиває спільнота. Вона має найновіші драйвери Linux і кілька варіантів: **настільний (Bazzite)**, **для портативних пристроїв і HTPC (Bazzite-Deck)** і **для розробників (Bazzite-DX, Developer eXperience)**. Bazzite побудовано на основі [**Fedora Linux**](https://fedoraproject.org/), і вона має [**атомарну систему оновлень**](https://github.com/bootc-dev/bootc), завдяки якій попереднє оновлення завжди доступне, якщо щось піде не так.

Вона також придатна для щоденного використання й зосереджена на **іграх**, **мультимедіа** та **розробці**. Крім того, оскільки Bazzite постачається з найновішими драйверами, можна бути певним: якщо ваш пристрій може працювати в Linux, він працюватиме і в Bazzite. Bazzite підтримує відеокарти **AMD**, сучасні **Nvidia** та **Intel**. Bazzite також добре працює на портативних пристроях **Lenovo**, **Asus**, **Ayn**, **GPD** і **OneXPlayer**.

### Додаткові переваги Bazzite порівняно зі SteamOS { #extra-enhancements-on-bazzite-compared-to-steamos }

-   Підтримка **подвійного завантаження** з **Windows**.
-   Працює на **більшості** портативних пристроїв на x86: Lenovo Legion Go/S, ASUS ROG Ally/X, варіанти OneXPlayer F1/G1/X1, GPD Win 4/Mini/Max, Ayn Loki, MSI Claw 1st Gen AI7+/8+, Zotac Zone, Ayaneo Air/Geek/Next, Steam Deck LCD/OLED.
-   Підтримка налаштування настільних відеокарт і вентиляторів.
-   **Оновлення без страху**
  -   **Попередня версія** завжди доступна через завантажувач.
  -   На портативних пристроях Bazzite автоматично повертається до попередньої версії після 3 невдалих завантажень.
  -   Доступні **оновлення за останні 90 днів**, і до будь-якої з цих версій можна легко повернутися однією командою.
-   Постачається з **найновішим доступним програмним забезпеченням**, зокрема **ядром Linux**, **драйверами відеокарт** і [**Gamescope**](https://github.com/ValveSoftware/gamescope).
-   Актуальні версії **KDE Plasma** або **GNOME** залежно від образу.
-   Корисне **програмне забезпечення для ігор**, як-от **Lutris, ScopeBuddy GUI, ProtonUp-QT/ProtonPlus, Protontricks** тощо.
-   Робоче середовище **GNOME** як альтернатива KDE Plasma.
-   Підтримка **віртуалізації** і **передавання відеокарти у віртуальну машину** (GPU passthrough) через Flatpak.
-   **Android-застосунки** можна встановлювати за допомогою [Waydroid](../Installing_and_Managing_Software/Waydroid_Setup_Guide.md).
-   Спрощене встановлення [**Sunshine**](../Advanced/sunshine.md) через Bazzite Portal, щоб легко транслювати свої ігри.
-   **[Bazzite Portal](../Installing_and_Managing_Software/Bazzite_Portal.md)** містить зручні скрипти [`ujust`](../Installing_and_Managing_Software/ujust.md) для налаштування програм і системи (наприклад, Secure Boot) і встановлення додаткового програмного забезпечення.
-   Використовує файлову систему **BTRFS** з **дедуплікацією** і **стисненням** (SteamOS використовує **Ext4**) і підтримує **автоматичне монтування** як **внутрішніх дисків**, так і **SD-карток**.

### Щоденне використання { #daily-driving }

-   Системні пакети часто оновлюються.
-   У режимі робочого столу використовується Wayland, тож масштабування на екранах із високою роздільною здатністю (high-DPI) працює правильно.
-   Більшість пакетів робочого столу дотримуються життєвого циклу Fedora. Винятки бувають, коли в пакеті є помилка: тоді його вибірково затримують або виправляють раніше, ніж у Fedora.

### Для розробників { #for-developers }

-   Доступ до багатьох менеджерів пакетів і репозиторіїв у контейнерах за допомогою [Distrobox](https://distrobox.it).
-   [Homebrew](https://brew.sh/) попередньо встановлено для програм командного рядка.
-   [Накладайте](../Installing_and_Managing_Software/rpm-ostree.md) пакети Fedora на систему, і вони зберігатимуться між оновленнями системи.
-   Більше інформації — у розділі [Development](https://dev.bazzite.gg).

### Покращення безпеки { #security-improvements }

Bazzite підтримує шифрування диска LUKS, Secure Boot і розблокування зашифрованого диска через TPM. Також у Bazzite за замовчуванням увімкнено й налаштовано [SELinux (Security Enhanced Linux)](https://www.redhat.com/en/topics/linux/what-is-selinux).

Підтримка Secure Boot корисна й для подвійного завантаження з Windows, бо вона потрібна для деяких античитів.
>Докладніше в [**посібнику з Secure Boot**](./Installation_Guide/secure_boot.md).
