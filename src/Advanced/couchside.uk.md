# Налаштування Couchside

[![GitHub Release](https://img.shields.io/github/v/release/emerytech/couchside?label=Latest%20Release&color=brightgreen&logo=github&logoColor=white)](https://github.com/emerytech/couchside/releases)

## Призначення { #purpose }

[**Couchside**](https://couchside.tv) перетворює ваш телефон на панель стану, пульт віддаленого керування й ігровий
контролер для HTPC або портативного пристрою з Bazzite, тож ви можете керувати системою з дивана, навіть
коли на телевізорі чорний екран. Він складається з рідного застосунку для iOS і Android та невеликої
служби на Python без залежностей, яка працює на самому пристрої.

З телефона можна:

- Бачити **показники в реальному часі**: температуру процесора, навантаження, пам'ять, диск, час роботи, стан служб systemd і
  (на портативних пристроях) батарею.
- **Виправити завислий сеанс без клавіатури**: перезапустити графічний сеанс, коли gamescope показує
  чорний екран, перемкнутися між ігровим режимом і робочим столом, перезавантажити або вимкнути пристрій.
- **Читати журнали** й отримувати знімок того, що зараз на екрані пристрою.
- **Запускати ігри** зі своєї бібліотеки Steam у вигляді сітки обкладинок.
- Скористатися **віртуальним контролером Xbox 360**, сенсорною панеллю або пультом, як у телевізора.

Він працює **лише в локальній мережі**: без хмари, облікових записів і аналітики. Агент на пристрої безплатний і з відкритим
кодом (MIT), а застосунок для телефона є в App Store і Google Play.

!!! note

    Couchside працює як служба `systemd --user` під вашим власним обліковим записом, використовуючи стандартні
    засоби Bazzite (`uinput` для віртуального контролера, `steamos-session-select` /
    `gamescope` для перемикання між ігровим режимом і робочим столом). Йому **не потрібне накладання пакетів через `rpm-ostree`**, і він
    **не** змінює кореневу файлову систему, доступну лише для читання.

## Встановлення { #installation }

Щоб встановити агент, виконайте в терміналі на пристрої:

```bash
curl -fsSL https://couchside.tv/install.sh | bash
```

Інсталятор налаштує службу користувача й покаже на екрані пристрою **QR-код для з'єднання** (під час
нового встановлення він проведе вас через з'єднання прямо там). Потім:

1. Встановіть застосунок **Couchside** на телефон з [App Store](https://apps.apple.com/us/app/id6786884115)
   або [Google Play](https://play.google.com/store/apps/details?id=com.ets3d.rescueremote).
2. Відкрийте застосунок, торкніться **Scan for boxes** і або відскануйте QR-код, або введіть **6-значний PIN-код**, який
   пристрій показує на своєму екрані.

!!! tip

    Пристрій і телефон мають бути в **одній локальній мережі**. Для з'єднання не потрібно вручну вводити IP-адреси
    чи токени: PIN-коду на екрані пристрою достатньо.

!!! note "Як забезпечується безпека"

    Агент виконує лише чітко визначений і перевірений **список дозволених** дій: жодна команда з телефона
    не виконується як довільна. Доступ дає один токен (bearer token), який створюється на пристрої під час
    встановлення й зберігається локально. Він ніколи не надсилається на жоден сервер за межами вашої локальної мережі.

## Видалення { #uninstall }

Щоб видалити агент (перед видаленням токена він запитає підтвердження):

```bash
curl -fsSL https://couchside.tv/install.sh | bash -s -- --uninstall
```
