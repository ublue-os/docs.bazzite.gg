# Створення власного образу Bazzite

## Коли це потрібно { #use-cases }

- Ви хочете замінити попередньо встановлені системні застосунки та інші типові налаштування, але залишатися близько до Bazzite, щоб автоматично отримувати покращення.
  - Наприклад: Waydroid вбудовано в образ Bazzite, але типово він не налаштований і не запущений. Якщо ви хочете, щоб цього пакета не було, його можна замінити або вилучити.
  - Вам потрібно накласти щось на кшталт VPN-програми, яка має бути в образі, але ви не хочете підтримувати власний окремий образ. (_Похідний образ від чужого завжди створювати легше_)
  - Ви хочете образ для особистого користування зі зміненими налаштуваннями та програмами, але й надалі отримувати покращення з основного проєкту.
  - Інші робочі середовища чи віконні менеджери, ніж ті, що пропонує Bazzite.
- Ви хочете допомагати в розробці Bazzite й мати змогу перевіряти свої зміни, перш ніж надсилати їх спільноті.
  - Підтримка обладнання, експериментальні функції, перевірка виправлень до злиття.

## Рекомендовані способи { #recommended-methods }

### Варіант A — шаблон образу { #option-a-using-the-image-template }

Щоб створити власний образ на основі Bazzite, краще використовувати [**офіційний шаблон образу**](https://github.com/ublue-os/image-template), ніж робити форк проєкту.

#### Відеоінструкція { #video-guide }

https://www.youtube.com/watch?v=IxBl11Zmq5w

### Варіант B — форк Bazzite { #option-b-forking-bazzite }

Іноді не потрібно створювати цілком новий образ з нуля, а лише змінити дещо без зайвої роботи, зробивши **форк Bazzite**. Щоб ваш форк залишався синхронізованим, дуже рекомендуємо використовувати [**застосунок Pull для GitHub**](https://github.com/apps/pull).

### Варіант C — BlueBuild { #option-c-using-bluebuild }

[**BlueBuild**](https://blue-build.org/learn/universal-blue/) — проєкт, який починався як відправна точка для створення власних образів Universal Blue і згодом став окремим проєктом. Усі питання щодо образів BlueBuild слід надсилати у відповідні [канали спілкування](https://blue-build.org/community/), а не в Universal Blue.
