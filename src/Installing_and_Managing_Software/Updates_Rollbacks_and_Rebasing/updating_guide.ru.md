# Руководство по обновлениям

![System Updates|200x200, 100%](../../img/System_Updates.png)

## Обновление Bazzite

!!! attention

    Для корректного обновления нужно, чтобы на диске, где установлен Bazzite, было свободно 3% от общего объема.

Bazzite подтягивает собственные изменения проекта, обновления базовых пакетов Fedora, графические драйверы и пользовательские приложения, установленные из Bazaar.

### Desktop-образы

- Обновления системы выполняются **автоматически каждый день** по расписанию, когда оборудование не находится под высокой нагрузкой, например во время игры.
    - Есть проверка, которая разрешает обновлять образ только тогда, когда загрузка CPU, батарея и использование RAM соответствуют нужным требованиям.
- Обновления загружаются в фоне и **применяются при следующей перезагрузке**. В них должна быть самая свежая сборка Bazzite.
    - При необходимости обновление можно запустить вручную через инструмент System Update.
- Системные пакеты, Steam и установленные приложения обновляются, когда для них доступны новые версии.

### Bazzite-Deck-образы

- В Steam Gaming Mode пользователь может управлять обновлениями **вручную**.
  - Откройте: **Steam Menu** > **Settings** > **System** > **Check for Updates** > **Apply**
    - Выполните **Reboot**, чтобы применить обновления системы.
- Системные пакеты, Steam и установленные приложения обновляются, когда для них доступны новые версии.

### Команда терминала (ручное обновление, все образы)

```command
ujust update
```

## Нужно ли перезагружаться сразу после каждого обновления системы?

**Нет**, но **обновление системы не применится до следующей перезагрузки**. Установленные пользователем приложения из Bazaar **можно обновлять без перезагрузки**.

- **Desktop-образы**: пока устройство работает, новые обновления все равно будут загружаться в фоне раз в день и ждать применения до перезагрузки устройства.
- **Bazzite-Deck-образы**: проверка обновлений выполняется ежедневно, а загрузить их можно в удобное время, примерно так же, как это работает в SteamOS.

## Как посмотреть список изменений для каждого обновления?

Списки изменений для каждого выпуска Bazzite доступны на [GitHub](https://github.com/ublue-os/bazzite/releases).

## Тарифицируемые / ограниченные сетевые подключения и лимиты трафика

!!! note
    Эта конфигурация не поддерживается, так как ожидается, что обновления операционной системы и приложений будут выполняться ежедневно.

Откройте системные настройки своего окружения рабочего стола и включите параметр, связанный с тарифицируемым подключением (лимиты трафика или возможные дополнительные расходы). Этот параметр **приостановит** автоматические обновления Bazzite.
