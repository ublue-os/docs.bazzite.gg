# Откаты

## Откат обновлений

Вернитесь к предыдущему обновлению системы, если после обновления возникли серьезные проблемы. Это можно сделать через меню GRUB, команду `rpm-ostree rollback` или Bazzite Rollback Helper.

## Как откатить обновление системы?

Откат к предыдущему развертыванию системы можно выполнить, **введя эту команду в терминале хоста**:

```command
rpm-ostree rollback
```

### Использование утилиты Bazzite Rollback Helper (`brh`)

Откатитесь на более старый образ Bazzite за последние 90 дней с помощью **[команды `brh`](../Updates_Rollbacks_and_Rebasing/bazzite_rollback_helper.md)**.

### Перед загрузкой Bazzite (GRUB)

![Меню GRUB с двумя развертываниями и настройками прошивки UEFI](../../img/GRUB_Menu.png)

!!! note

    Управление для навигации по меню может отличаться на разных портативных устройствах и HTPC, а для отката в GRUB может потребоваться внешняя физическая клавиатура.

Откат также можно выполнить в меню GRUB, которое открывается перед загрузкой Bazzite, выбрав предыдущий пункт загрузки до перехода на рабочий стол. В нем показаны текущее (`:0`) и предыдущее (`:1`) развертывания. Ваши личные файлы при этом **не** будут затронуты, и после отката вы все равно сможете обновиться до новейших сборок.

## Как сохранить **текущее** развертывание?

Вы можете закрепить **текущее** развертывание этой **командой**:

```command
sudo ostree admin pin 0
```

Выполните ее в терминале хоста, чтобы сохранить резервное состояние **текущего** развертывания для отката, если новое обновление системы вызовет проблемы.

## Как сохранить **предыдущее** развертывание?

Вы можете закрепить **предыдущее** развертывание этой **командой**:

```command
sudo ostree admin pin 1
```

Выполните ее в терминале хоста, чтобы сохранить резервное состояние **предыдущего** развертывания для отката, если с текущим развертыванием возникнут проблемы.

## Как открепить развертывание, если я его сохранил?

Открепить сохраненное **текущее** развертывание:

```command
sudo ostree admin pin --unpin 0
```

Открепить сохраненное **предыдущее** развертывание:

```command
sudo ostree admin pin --unpin 1
```

Показать все номера индексов развертываний:

```command
rpm-ostree status -v
```

Открепить **сохраненное** развертывание:

```command
sudo ostree admin pin --unpin <index number>
```
