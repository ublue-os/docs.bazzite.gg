# Bazzite Rollback Helper (`brh`)

![brh|916x606, 100%](../../img/brh.png)

!!! note

    Bazzite Portal показывает команды Bazzite Rollback Helper в графическом интерфейсе.

## Назначение

`bazzite-rollback-helper` - инструмент командной строки для отката системных обновлений или смены потока обновлений. С его помощью можно откатиться к сборке Bazzite за последние 90 дней, перейти на другой образ и посмотреть сведения о текущем образе Bazzite.

## Использование `bazzite-rollback-helper`

Откройте терминал хост-системы и **введите**:

```command
bazzite-rollback-helper
```

Также есть короткий **алиас**. Он удобнее на портативных устройствах и HTPC без клавиатуры:

```command
brh
```

## Доступные параметры

- `list` = показать образы за последние 90 дней, на которые можно перейти.
- `rollback` = откатиться к предыдущему развертыванию при следующей перезагрузке.
- `current` = показать сведения о текущем развертывании и образе.
- `rebase` = перейти на другую сборку, ветку обновлений или другой образ Fedora **на свой риск**.

### Примеры

`bazzite-rollback-helper list` покажет доступные образы Bazzite.

`bazzite-rollback-helper rebase <image-name:stable>` выполнит переход на более ранний образ, другую ветку обновлений или другой образ Bazzite (Desktop или Bazzite-Deck). Подходящую версию можно найти командой `list`.

### Переход на более старый образ Bazzite

**Пример**: `bazzite-rollback-helper rebase stable-40.20240930.0`
<sub>(Этот образ приведен только как пример. Сейчас к нему уже нельзя откатиться, потому что он слишком старый.)</sub>

Переход на конкретный образ закрепит систему на этом образе ОС. Новые функции и обновления безопасности не будут применяться, пока вы не вернетесь на канал обновлений Stable.

Когда ошибка, мешавшая использовать канал Stable, будет исправлена, вернитесь к обычным обновлениям ОС:
`bazzite-rollback-helper rebase stable`
