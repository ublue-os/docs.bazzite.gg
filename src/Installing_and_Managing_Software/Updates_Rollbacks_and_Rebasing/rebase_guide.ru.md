# Руководство по переходу на другой образ

## Что такое переход на другой образ?

!!! warning

    Переход между разными окружениями рабочего стола (например, с KDE Plasma на GNOME) **может вызвать проблемы** и **не поддерживается**.

Переход на другой образ позволяет пользователям переключиться на другой образ **без** переустановки системы, потери личных файлов и данных приложений.

>[**Рекомендуется использовать утилиту Bazzite Rollback Helper**](./bazzite_rollback_helper.md).

## Сценарии перехода на другой образ

- Переход на конкретные образы старых сборок за последние 90 дней, если в новейшей сборке Bazzite возникают проблемы.
- Переход на другие образы Fedora Atomic Desktop, включая другие образы Bazzite.
  - **Не** переходите между разными окружениями рабочего стола.

## Как переключаться между образами Bazzite?

Посмотрите, на каком канале или сборке вы находитесь, **введя эту команду в терминале хоста**:

```command
rpm-ostree status
```

Проверьте раздел "**Deployments:**". Вывод должен быть похож на следующий:
```
 ● ostree-image-signed:docker://ghcr.io/ublue-os/[*image*]:[*channel*]
```

Переключитесь на другой вариант Bazzite, введя команду для нужного образа.

Откройте терминал и **введите**:

```
rpm-ostree rebase <image>
```

### **Пример**:

!!! warning

    Переход между разными окружениями рабочего стола (например, с KDE Plasma на GNOME) **может вызвать проблемы** и **не поддерживается**.

```command
rpm-ostree rebase ostree-image-signed:docker://ghcr.io/ublue-os/bazzite-deck:stable
```

Для перехода на версию KDE Plasma образа Bazzite-Deck.

## Как изменить ветку обновлений Bazzite? (Stable, Testing и Unstable)

Для обычных пользователей предназначены две ветки обновлений:

- Stable (`:stable`)
  - Ветка по умолчанию, используемая при обычной установке Bazzite.
- [Testing (`:testing`)](https://github.com/ublue-os/bazzite/compare/main...testing)
  - Позволяет заранее опробовать будущие сборки Bazzite до релиза.
  - Ошибки могут появляться часто.
  - После тестирования крупного релиза рекомендуется вернуться на `:stable`.

### Ветка Unstable

Она предназначена только для основных участников и сопровождающих Bazzite и используется для крупных изменений, которым нужно частое тестирование. Ветка unstable может отставать по обновлениям даже от stable, так как в ней тестируются конкретные крупные изменения, а сама она не собирается по расписанию.

## Переключение веток обновлений в Steam Gaming Mode
  
Образы Bazzite-Deck могут переключать ветки в `Settings > System > OS Update Channel` в Steam Gaming Mode.

Если вы включили **advanced update channel**, появятся дополнительные варианты. Они соответствуют следующим веткам:

```
Stable (:stable)
Release Candidate (:testing)
Beta (:testing)
Beta Candidate (:unstable)
Main (:unstable)
```

###  **Пример**:

```command
rpm-ostree rebase ostree-image-signed:docker://ghcr.io/ublue-os/bazzite:testing
```

Для ветки **testing** на образе AMD/Intel Desktop.

## Переход на старые сборки

!!! attention

    Когда вы захотите обновиться до новейшего релиза, вам нужно будет вернуться на `:stable`.

!!! warning

    При переключении на старые сборки Bazzite новые обновления не будут поступать, пока вы не вернетесь на `:stable`. Это значит, что обновлений безопасности не будет до возвращения на стабильную ветку.

Как и при откате к предыдущему развертыванию Bazzite, пользователи также могут перейти на конкретные сборки Bazzite, созданные за последние 90 дней. Все ваши пользовательские данные останутся нетронутыми, но, как указано в предупреждении выше, для обновления системы и получения новейшей сборки вам нужно будет вручную вернуться на `:stable`.

Посмотрите список доступных стабильных сборок, **введя**:

```command
skopeo list-tags docker://ghcr.io/ublue-os/bazzite | grep -- "stable-" | sort -rV
```

Для перехода на конкретную сборку пользователю нужно открыть терминал хоста и **ввести**:

```command
rpm-ostree rebase ostree-image-signed:docker://ghcr.io/ublue-os/IMAGE-NAME:VERSION-YEARMONTHDAY
```

**Пример**:

```command
rpm-ostree rebase ostree-image-signed:docker://ghcr.io/ublue-os/bazzite-deck:39-20240113
```

Для сборки `bazzite-deck` (_Fedora 39_) от _13 января 2024 г._.

<small>_(Обратите внимание: эта сборка больше недоступна, так как вышла за пределы 90-дневного лимита, и используется здесь только как пример для документации.)_</small>
