# Посібник з оновлення

![System Updates|200x200, 100%](../../img/System_Updates.png)

## Оновлення Bazzite

!!! attention

    Для коректного оновлення Bazzite потрібно щонайменше 3% вільного місця на диску, на який встановлено систему.

Bazzite оновлює власні налаштування, пакети з Fedora, графічні драйвери та всі програми, встановлені через Bazaar.

=== "Образи для настільних ПК"

    Bazzite для настільних ПК **щодня автоматично перевіряє** наявність оновлень і встановлює їх, коли система простоює, наприклад, коли ви не граєте й не запускаєте важких завдань.
    
    - Окрема перевірка дозволяє оновлювати образ лише тоді, коли навантаження на процесор, заряд батареї та використання RAM відповідають певним вимогам.

    Оновлення завантажуються у фоні, **застосовуються після наступного перезавантаження** і мають містити найновішу збірку Bazzite. Також можна перевірити наявність оновлень і встановити їх вручну за допомогою [**Bazzite Updater**](./bazzite_updater.md).

    !!! info "Зазвичай стабільні образи оновлюються раз на [два тижні](https://en.wikipedia.org/wiki/Fortnight)."

=== "Образи Bazzite-Deck"

    В образах Bazzite Deck автоматичні оновлення за замовчуванням **вимкнено**.

    - Користувач може керувати оновленнями **вручну** в ігровому режимі Steam.
    - Відкрийте **Steam Menu → Settings → System → Check for Updates → Apply**
      - Також можна скористатися [**Bazzite Updater**](./bazzite_updater.md).
      - Щоб застосувати оновлення системи, просто **перезавантажтеся**.

=== "Команда в терміналі"

    Оновити систему можна такою командою, якщо:
    
    - графічний сеанс не запускається 
    - ви підключені через `ssh`
    - ви працюєте в `tty`.

    ```bash
    ujust update
    ```
    
    !!! note "Якщо із системою виникли проблеми, зверніться по допомогу на [Discord-сервер Bazzite](../../community.md#discord-no-discord-account)"

## Чи потрібно перезавантажуватися одразу після кожного оновлення системи?

**Ні**, але **оновлення системи не застосується до наступного перезавантаження**. Застосунки, встановлені з Bazaar, **можна оновлювати без перезавантаження**.

- **Образи для настільних ПК**: поки пристрій працює, нові оновлення все одно завантажуються у фоні раз на день і чекають на перезавантаження пристрою.
- **Образи Bazzite-Deck**: наявність оновлень перевіряється щодня, а завантажити й встановити їх можна, коли вам зручно, — так само як у SteamOS.

## Як переглянути список змін для кожного оновлення?

Списки змін можна переглянути в [Bazzite Updater](./bazzite_updater.md#viewing-changelogs) або на сторінці [GitHub Releases](https://github.com/ublue-os/bazzite/releases).

!!! tip "Під час перегляду звертайте увагу на свою **поточну версію образу** та гілку. Багато релізів призначені лише для гілки **testing**."

Також можна переглянути **різницю в пакетах** між поточним і наступним образом такою командою:

```bash
rpm-ostree db diff
```

Крім того, можна переглянути **інформацію про оновлення безпеки** такою командою:

```bash
rpm-ostree status -a
```

## Лімітовані з'єднання та обмеження трафіку

!!! note

    Така конфігурація не підтримується, оскільки оновлення операційної системи та застосунків мають запускатися щодня.

Відкрийте системні налаштування свого робочого середовища й увімкніть параметр, пов'язаний із лімітованим з'єднанням (обмеженням трафіку чи платним трафіком).  Цей параметр **призупинить** автоматичні оновлення Bazzite.
