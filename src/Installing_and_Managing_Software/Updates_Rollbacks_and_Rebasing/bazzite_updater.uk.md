# Bazzite Updater

![Bazzite Updater|1703x1137, 50%](/img/bazzite-updater.png)

!!! info "Bazzite Updater з'явився в релізі Bazzite 44!"

Новий **Bazzite Updater**, створений [Robert French](https://github.com/rfrench3), дає змогу оновлювати систему, відкочувати оновлення й переглядати списки змін у графічному інтерфейсі, і ним можна повністю керувати за допомогою контролера!

---

## Використання

### Оновлення

Просто натисніть кнопку оновлення. Щоб стежити за ходом оновлення, натисніть кнопку **Toggle Console** у **верхньому правому куті**.

---

### Перегляд списку змін { #viewing-changelogs }

![Bazzite Updater Changelogs|1683x1137, 50%](/img/bazzite-updater-changelogs.png)

Списки змін можна переглянути, вибравши пункт **Changelogs** у меню-«гамбургері» у **верхньому лівому куті**.

!!! tip "Під час перегляду звертайте увагу на свою **поточну версію образу** та гілку. Багато релізів призначені лише для гілки **testing**."

---

### Відкат оновлень { #rollback-updates }

![Bazzite Updater Utilities|1751x1163, 50%](/img/bazzite-updater-utilities.png)

Відкотити оновлення можна, вибравши пункт **Other Utilities** у меню-«гамбургері» у **верхньому лівому куті**.

---

## Додавання Bazzite Updater до Steam

![Add Bazzite Updater to Steam|897x612, 50%](/img/bazzite-updater-add-to-steam.png)

У [Bazzite Portal](../Bazzite_Portal.md) виберіть **Manage Bazzite → Update your system → Add Bazzite Updater to Steam Big Picture**.
