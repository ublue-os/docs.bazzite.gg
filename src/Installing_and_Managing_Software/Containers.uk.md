# Контейнери

## Що таке контейнери? { #what-are-containers }

Контейнери — ізольовані середовища, у яких працюють програми. Bazzite використовує контейнери для застосунків, які або краще працюють у контейнері, або недоступні в магазині застосунків Bazaar.

## Distrobox { #distrobox }

[**Distrobox**](./Distrobox.md) дає змогу запускати мінімальні версії інших операційних систем Linux у власному контейнерному середовищі з доступом до їхніх репозиторіїв. Приклад із практики — застосунки, які підтримують у Linux лише Ubuntu і пропонують на своєму сайті файл `.deb`. Можна створити контейнер Ubuntu у Kontainer (на нових встановленнях з KDE Plasma) або DistroShelf (на образах з GNOME і старіших встановленнях з KDE Plasma), встановити в ньому файл `.deb` і експортувати застосунок, щоб він з'явився в меню застосунків.

[**Quadlet**](./Quadlet.md) використовують саме для запуску служб, як-от медіасерверів, ігрових серверів тощо. Quadlet складніший за інші формати пакетів і значною мірою спирається на системні інструменти, попередньо встановлені в Bazzite. Команди `quadlet` немає: служби створюють декларативно за допомогою модулів systemd і Podman.
