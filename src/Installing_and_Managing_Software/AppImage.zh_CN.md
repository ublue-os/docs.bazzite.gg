# AppImage

![AppImage|100x100, 100%](../img/AppImage.png)

AppImage 是一个通用化的包装格式，通过将应用程序和所有相关的依赖组件打包成一个文件以方便分发。用户只需要下载这个通常使用`.AppImage`后缀名的文件并授予执行权限，即可直接运行。AppImage 文件的分发通常类似于 Windows 版，即直接从项目官方下载。当然，下载任意文件时应注意来源等信息，防止下载到恶意软件。

## Gear Lever

![Gear Lever|500x500](../img/Gear_Level.png)

Bazzite 预安装了 [Gear Lever](https://github.com/mijorus/gearlever) 这一实用工具来将 AppImage 的运行与管理更有效地集成到桌面逻辑当中。你也可以从 [Bazaar](./Flatpak.md) 手动下载它。Gear Lever 支持自动检查已安装的 AppImage 的更新，但目前**安装更新仍需要手动进行**。我们强烈推荐使用 Gear Lever 进行 AppImage 管理。
