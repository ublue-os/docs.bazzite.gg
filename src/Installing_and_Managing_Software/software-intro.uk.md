# Вступ до встановлення програм у Bazzite

## Формати пакетів Linux { #linux-package-formats }
**Формати пакетів від найбільш до найменш рекомендованих для щоденного використання**:

1. [**Bazzite Portal (команди `ujust`)**](./Bazzite_Portal.md) (_зручні команди_) — власні скрипти, які підтримують учасники Bazzite і Universal Blue. Вони також можуть встановити невеликий набір застосунків. <small>(Цей спосіб має перевагу над іншими форматами, але оскільки він встановлює лише невеликий набір програм, його вважають розширенням системних налаштувань, а не магазином застосунків.)</small>
2. [**Магазин застосунків Bazaar (Flatpak)**](./Flatpak.md) (_графічні застосунки_) — універсальний формат пакетів із моделлю дозволів. Його варто використовувати для більшості графічних застосунків, **це основний спосіб отримувати програми в Bazzite**.
3. [**Homebrew**](./Homebrew.md) (_інструменти командного рядка_) — встановлення застосунків, які працюють у терміналі (CLI/TUI).
4. [**Контейнери**](./Containers.md) — запуск застосунків в ізольованому середовищі, щоб уникнути проблем із залежностями.
    4a. [**Контейнери Distrobox**](./Distrobox.md) (_пакети Linux і робочі процеси розробки_) — доступ до більшості менеджерів пакетів Linux для програм, які не підтримують Flatpak і Homebrew, а також для середовищ розробки.
    4b. [**Quadlet**](./Quadlet.md)  (_служби_) — запуск застосунків у контейнерах як [служби systemd](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/7/html/system_administrators_guide/chap-managing_services_with_systemd#sect-Managing_Services_with_systemd-Services).
5. [**AppImage**](./AppImage.md) (_портативні графічні застосунки_) — портативний універсальний формат пакетів, який залежить від певних бібліотек хост-системи. Зазвичай їх завантажують із сайту проєкту.
6. [**`rpm-ostree`**](./rpm-ostree.md) (_системні пакети_) — накладання пакетів Fedora на рівні системи (**не рекомендовано, використовуйте лише в крайньому разі**)

## Формати не для Linux { #non-linux-formats }

Bazzite також може запускати застосунки для Windows і Android. Зверніть увагу, що не всі програми для Windows і Android працюватимуть у Bazzite.

### Виконувані файли Windows { #windows-executables }

**Використовуйте оболонку для [WINE](https://www.winehq.org/)**:

- [**Steam**](https://store.steampowered.com/) (_попередньо встановлено_) має вбудований шар сумісності з Windows.
- [**Lutris**](https://lutris.net/about) (_попередньо встановлено_) для ігор для ПК не зі Steam і неігрових програм.
- [**Faugus Launcher**](https://github.com/Faugus/faugus-launcher) (_доступний у Bazaar_) як альтернатива Lutris.
- [**Heroic Games Launcher**](https://heroicgameslauncher.com/) (_доступний у Bazaar_) для повноцінної інтеграції з Epic Games, GOG і Amazon Games.
- [**Greenlight**](https://flathub.org/en/apps/io.github.unknownskl.greenlight) (_доступний у Bazaar_) для трансляції ігор із магазину Windows і Game Pass. <small>(**Лише трансляція**)</small>
- [**WineZGUI**](https://github.com/fastrizwaan/WineZGUI) (_доступний у Bazaar_) для простіших застосунків Windows, які не потребують особливих налаштувань.

>Докладніше про запуск ігор для Windows у Linux читайте в [**посібниках Bazzite з ігор**](../Gaming/index.md).

### Android-застосунки { #android-apps }

Щоб встановлювати Android-застосунки в Bazzite, скористайтеся [**посібником з налаштування Waydroid**](./Waydroid_Setup_Guide.md).

## Який формат пакетів вибрати { #package-format-recommendation-scenarios }

!!! note
        
        У Bazzite Portal можна встановити лише невеликий набір програм, тому його не наведено нижче.

![Схема вибору способу встановлення програм](../img/software-install-decision-tree-light.svg#only-light)
![Схема вибору способу встановлення програм](../img/software-install-decision-tree-dark.svg#only-dark)


| **Формат пакетів** | **Графічний застосунок (GUI)** | **Застосунок командного рядка / системний пакет** |
|--------------------|----------------------------------|------------------------------------------|
| **Магазин застосунків Bazaar (Flatpak)** | Основний спосіб отримувати графічні застосунки. | Не рекомендовано для застосунків і утиліт командного рядка. |
| **Homebrew** | Рекомендовано лише для кількох графічних застосунків (наприклад, VSCode через [cask від Universal Blue](https://github.com/ublue-os/homebrew-tap)). | Дуже рекомендовано для інструментів командного рядка. |
| **Контейнери (Distrobox / Quadlet)** | Якщо застосунку немає в Bazaar, встановіть звичайний пакет Linux у контейнері Distrobox і експортуйте його. Для служб створіть Quadlet. | Рекомендовано, якщо пакета Homebrew немає. |
| **AppImage** | Шукайте AppImage в інтернеті на власний ризик і лише з надійних джерел. Для правильної інтеграції із системою використовуйте Gear Lever (доступний у Bazaar). | — |
| **Накладання пакетів** | Якщо жоден із варіантів вище не підходить, накладіть пакет на власний ризик. | Накладайте лише тоді, коли жоден інший варіант не підходить. |
| **Інше** | Деякі програми постачаються як архів `.tar.gz` із виконуваним файлом. Він *може* запрацювати в Bazzite, якщо у властивостях файлу дозволити його виконання. Також можна запустити версію для Windows через оболонку для Wine (наприклад, Lutris). Якщо є версія для Android, може спрацювати Waydroid. | — |
| **[Власний образ](../Advanced/creating_custom_image.md)** | — | Для інших робочих середовищ або програм для незвичайного обладнання може знадобитися власний образ Bazzite. |
