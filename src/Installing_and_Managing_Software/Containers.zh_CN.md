# 容器

## 容器是什么？

容器是供软件运行的相对独立化的操作环境。对于 Bazaar 应用商店上不提供或更适合容器化运行的软件，Bazzite 可能会默认配置容器来运行它们。

## Distrobox

[**Distrobox**](./Distrobox.md) 提供最小化的其他发行版的运行环境，允许用户在其中访问这些发行版的软件仓库。一种常见的使用场景是只提供 Ubuntu 或类似系统支持因此只提供`.deb`软件包的应用程序，只需要创建一个 Ubuntu 的容器，即可直接安装它，并将安装完成的程序“导出”到主机层方便访问。

[**Quadlet**](./Quadlet.md) 则更适合长期运行的服务，比如媒体或游戏服务器。Quadlet 相对于其他的软件安装方式更为复杂：不存在一个单独的`quadlet`命令，而是需要调用系统组件去解析手动进行的 systemd 和 Podman 配置。
