# AppImage

![AppImage|100x100, 100%](../img/AppImage.png)

AppImage — універсальний формат пакетів, який намагається зібрати всі потрібні застосунку залежності в один портативний файл. Щоб встановити такий застосунок, завантажте будь-який файл із розширенням `.AppImage` і дозвольте його виконання у властивостях файлу, щоб застосунок міг правильно працювати. Як і виконувані файли Windows, їх зазвичай завантажують із сайту проєкту. Завантажуйте AppImage лише з джерел, яким ви довіряєте.

## Gear Lever { #gear-lever }

![Gear Lever|500x500](../img/Gear_Level.png)

Застосунки AppImage можна інтегрувати з робочим столом і керувати ними за допомогою [Gear Lever](https://github.com/mijorus/gearlever), який можна встановити з [Bazaar](./Flatpak.md). Gear Lever також перевіряє наявність оновлень, але **встановлювати їх усе одно доведеться вручну**. Для керування AppImage дуже радимо встановити Gear Lever.
