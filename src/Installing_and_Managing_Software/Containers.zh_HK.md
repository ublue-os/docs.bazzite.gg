# 容器

## 甚麼是容器？

容器是一個給予特定軟件運行的虛擬環境。 Bazzite 能為一些於 Bazaar 應用商店不提供、或是可以在虛擬環境內運行得更好的軟件提供容器支援。

---

## Distrobox

[**Distrobox**](./Distrobox.md) 為用戶提供一個運行其他 Linux 發行版的輕量化虛擬環境。 你可以在 Distrobox 中使用其他發行版的包管理器，如`dpkg`、`apt`、`dnf`、`pacman` 等等。若一種軟件只提供一個於網站上下載的`.deb`或`.rpm`包，那你便可以透過 Distrobox 輕易安裝該軟件。此外，你亦能使用 Distrobox 的各種 GUI，如 DistroShelf 和 Kontainer 等。

---

## Quadlet

[**Quadlet**](./Quadlet.md) 是一個將獨立容器鏡像視為系統服務運行的工具，你可於其上運行各種影像或遊戲伺服器。其能運行各種 Docker 或 Podman 的容器鏡像。
